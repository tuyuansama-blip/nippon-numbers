How to verify

This file is committed as predictions/j1_2026_2026-10-31.json in the project's git repository, with the SHA-256 shown above. On its own, a git commit timestamp is not strong third-party evidence that a prediction existed before kickoff — the author can set it to any date. Independent timestamping (OpenTimestamps), Wayback Machine archiving and a GitHub Actions server-time witness are part of this project's published plan for closing that gap (design document, section 3) and are not yet wired into this build. Until they are, verify what you can today: recompute the SHA-256 of the committed file yourself and confirm it matches the value above, and read the raw JSON — nothing on this page is derived from anything else.
